# Sena Learning Center — website

Website satu halaman responsif untuk **Sena Learning Center / Sensorium Nature School**, Prigen, Pasuruan. Dibuat dengan HTML, CSS, dan JavaScript murni; tidak membutuhkan framework, paket, atau font eksternal.

## Menjalankan secara lokal

Buka `index.html`, atau jalankan server statis dari folder ini:

```bash
python3 -m http.server 8000
```

Lalu buka `http://localhost:8000`.

## Fitur

- Tampilan editorial “nature field journal” dengan layout desktop dan mobile.
- Navigasi responsif, CTA WhatsApp, Instagram, TikTok, email, dan pencarian area Prigen.
- Filter kartu program, rincian program yang dapat dibuka, dan panduan rekomendasi kelas interaktif.
- FAQ accordion, animasi masuk yang menghormati pengaturan reduced motion, metadata SEO, dan schema.org.
- Logo Sena dari file yang diberikan dan seluruh foto Unsplash resolusi tinggi disimpan lokal di folder `assets/`; foto tidak dimuat dari CDN. Kredit foto tercatat di `IMAGE_CREDITS.md`.
- Ikon antarmuka memakai 20 glyph resmi Phosphor Icons Regular sebagai SVG inline lokal; lisensi disertakan di `THIRD_PARTY_NOTICES.md`.

## Catatan konten

Informasi program, pendiri, fasilitas, dan rincian paket dirangkum dari booklet profil Sena Learning Center 2024 yang diberikan untuk proyek ini serta deskripsi publik Instagram. Harga tidak ditambahkan karena tidak tercantum. Jadwal, ketersediaan kelas, alamat rinci, dan biaya sebaiknya dikonfirmasi melalui admin sebelum website dipublikasikan. Semua foto Unsplash bersifat ilustratif, bukan dokumentasi resmi kelas atau fasilitas Sena.
